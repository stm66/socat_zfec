Структура файла сканирования портов
Файл представляет собой строки следующей структуры:
<Port_dst> <path_to_ destination_folder>
Поле <Port_dst> используется для задания сканируемого порта,
поле <path_to_destination_folder> задает папку назначения для принятых файлов, которая ассоциируется с данным портом.
Пример файла сканирования портов:
55001 dest
55002 dest2
